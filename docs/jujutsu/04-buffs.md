# باف‌ها

> این سند مرجع مشخصات قانون است؛ وجود متن در این فایل به معنی پیاده‌سازی‌شدن قانون نیست. وضعیت اجرا را در [نقشه مرکزی](README.md) بررسی کن.

### ۳.۶. رنک پایه باف‌ها

| سطح باف | مقدار پایه |
|---|---:|
| ساده | 5 |
| سوپر | 15 |
| تقویت‌شده | 15 |
| ویژه | 25 |

قانون تکمیلی:
- سطح ساده بدون مصرف NP است.

موارد لازم:
- [x] تعریف داده ساختاریافته چهار سطح باف در `src/game/rules.js`: ساده (۵، رایگان)، سوپر (۱۵)، تقویت‌شده (۱۵) و ویژه (۲۵).
- [ ] تعریف نوع اثر باف: افزایش دمیج، دفاع، HP، NP یا اثر دیگر.
- [ ] تعیین مدت اثر: همان حرکت، همان راند، چند راند یا تا پایان بازی.
- [ ] تعیین هزینه NP سطوح غیرساده.
- [ ] تعیین امکان انباشته‌شدن چند باف و سقف آن‌ها.
- [ ] پیاده‌سازی اعمال، انقضا و پاک‌سازی باف‌ها.
