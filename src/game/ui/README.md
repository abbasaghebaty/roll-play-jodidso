# Game UI modules

| فایل | مسئولیت |
|---|---|
| `prompts.js` | ساخت پیام نوبت/دفاع، پاپ‌آپ‌ها و توابع مشترک کیبورد |
| `panel.js` | رندر و تازه‌سازی پنل ثابت لابی/نبرد و پیام نوبت |
| `callbacks.js` | تبدیل callbackهای `rp:` به عملیات handlerها |

`src/game/ui.js` مسیر سازگاری قبلی است و exportهای عمومی را نگه می‌دارد. منطق عددی و تغییر وضعیت بازی نباید در این پوشه قرار بگیرد.
