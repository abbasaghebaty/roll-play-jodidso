# Combat rules modules

تمام محاسبات این پوشه باید pure باقی بمانند: بدون Telegram، D1 یا تغییر مستقیم وضعیت بازی.

| فایل | مسئولیت |
|---|---|
| `constants.js` | ثابت‌های مشترک محاسبات |
| `dice.js` | جدول احتمال، تولید تاس، تاس حمله و برچسب نتیجه |
| `attack.js` | فرمول دمیج حمله و هزینه NP |
| `defense.js` | محاسبه مقدار دفاع |
| `ranks/attack.js` | جدول رنک و دمیج پایه حمله |
| `ranks/defense.js` | جدول رنک و مقدار پایه دفاع |
| `ranks/buffs.js` | جدول رنک باف |
| `index.js` | سطح عمومی exportها |

برای تغییر یک عدد رنک، فقط فایل همان رنک را تغییر بده. `src/game/rules.js` و `rules/index.js` مسیرهای تجمیع هستند؛ منطق جدید را داخل آن‌ها ننویس.
