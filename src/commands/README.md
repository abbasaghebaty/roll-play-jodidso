# Command modules

این پوشه پیاده‌سازی دستورها را بر اساس مسئولیت جدا می‌کند. فایل `src/commands.js` فقط مسیر سازگاری قدیمی را نگه می‌دارد.

| فایل | مسئولیت |
|---|---|
| `index.js` | دریافت آپدیت، ساخت context و اتصال نام دستور به handler |
| `admin.js` | دستورهای مستر: ساخت/بستن بازی، تیم، شروع، باف و وضعیت دستی |
| `players.js` | ثبت‌نام، فهرست شخصیت/تکنیک/دفاع و نمایش وضعیت |
| `combat.js` | حمله، دفاع، بدون‌دفاع و حل حمله‌های منتظر |
| `helpers.js` | ارسال پاسخ و تازه‌سازی پنل در صورت نیاز |

**قاعده:** فرمول‌های عددی در این پوشه تعریف نمی‌شوند؛ برای آن‌ها از `src/game/rules/` استفاده کنید. رابط دکمه‌ای نیز در `src/game/ui/` باقی می‌ماند.
